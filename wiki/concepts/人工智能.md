# 人工智能

> 被提及 2 次 | 分類：AI

## 核心要點

- 1. 同時跑 3-5 個 Claude Code 會話，用 Gatebox 隔離上下文，像管理 AI 團隊
- 2. 用 Claude Code 做重寫，用 Shell 封裝高频操作
- 3. 做了不止一次的事就封裝成流程，不靠記憶重複
- 4. CLI 優先於 MCP，更簡單更可靠
- 5. Claude Code 當學習工具，畫架構圖、理解陌生代碼庫
- 6. 平行不是更快，任務分配才是核心，避免多 Agent 改同一文件
- 7. 經常更新，小版本常含重大改進
- 8. 把 Claude 當可被塑造的協作者，持續優化人機協作
- 1. 探討 AI 技術如何改變編程和開發方式
- 2. AI 在代碼生成和優化中的應用
- 3. 技術創新對行業的衝擊
- 4. 學習 AI 工具提升工作效率
